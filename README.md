# 🌸 Bloom Garden - Flower Shop

A responsive flower shop website built using **HTML, CSS, Bootstrap, and JavaScript**.  
Users can browse flowers, add items to a cart, and manage purchases with LKR pricing. 

## ✨ Features
 
- 🏠 Home page with flower shop introduction
- 🌺 Flower product listing
- 🛒 Add to cart functionality
- ➕ Update quantity and remove items
- 💰 LKR (Rs.) price calculation
- 💾 Local Storage cart management
- 📞 Contact page
- 📖 About page
- 📱 Responsive design 

## 🛠️ Technologies 

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Local Storage
